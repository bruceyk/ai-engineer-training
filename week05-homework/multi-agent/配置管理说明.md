# 配置管理说明

## 🎯 配置统一管理

现在所有的配置都统一管理在 `app_config.py` 中，包括：

### 1. API Key 配置
```python
# 通义千问API配置
self.dashscope_api_key = os.getenv('DASHSCOPE_API_KEY') or "your_dashscope_api_key_here"
```

### 2. 模型配置
```python
# 通义千问模型配置
self.tongyi_config = {
    'model_name': 'qwen-turbo',
    'temperature': 0.7,
    'max_tokens': 2000,
    'top_p': 0.9,
}
```

### 3. 系统提示词配置
- **系统级提示词**: `system_prompt`
- **工作流阶段提示词**: 
  - `research_stage_prompt`
  - `writing_stage_prompt` 
  - `review_stage_prompt`
  - `editing_stage_prompt`

### 4. Agent工具提示词配置
所有17个Agent工具的提示词都在 `agent_prompts` 中统一管理：

#### 研究Agent工具
- `analyze_topic`
- `collect_background_info`
- `identify_key_concepts`
- `research_trends`

#### 写作Agent工具
- `create_article`
- `generate_title`
- `structure_content`
- `create_summary`

#### 审核Agent工具
- `evaluate_content_quality`
- `check_accuracy`
- `analyze_readability`
- `suggest_improvements`

#### 润色Agent工具
- `polish_content`
- `improve_language`
- `optimize_structure`
- `final_quality_check`
- `enhance_readability`

## 🔧 配置使用方式

### 在 mcp_client.py 中
```python
# 使用工作流阶段提示词
research_prompt = self.config.prompts['research_stage_prompt'].format(
    user_request=user_request
)
```

### 在 unified_mcp_server.py 中
```python
# 使用Agent工具提示词
prompt = config.prompts['agent_prompts']['analyze_topic'].format(topic=topic)
```

## ✅ 配置管理优势

1. **集中管理**: 所有配置都在一个文件中
2. **易于维护**: 修改提示词只需要在一个地方
3. **参数化**: 支持动态参数替换
4. **类型安全**: 统一的配置结构
5. **版本控制**: 配置变更可追踪

## 🎨 自定义配置

要自定义提示词，只需修改 `app_config.py` 中对应的配置项：

```python
# 例如：修改研究阶段提示词
'research_stage_prompt': """你的自定义提示词内容
支持参数: {user_request}
"""
```

这样的配置管理方式确保了系统的可维护性和扩展性。
