# 项目结构说明

## 📁 最终项目结构

```
multi-agent/
├── main.py                    # 🚀 主程序入口
├── app_config.py             # ⚙️ 配置管理
├── mcp_client.py             # 🤖 MCP客户端和LangGraph工作流
├── unified_mcp_server.py     # 🔧 统一MCP服务器(17个Agent工具)
├── requirements.txt          # 📦 依赖包列表
├── README.md                 # 📖 项目文档
├── .env.example             # 🔑 环境变量示例
└── __init__.py              # 📄 Python包标识
```

## 🔧 核心文件说明

### 1. main.py - 主程序
- **功能**: 系统入口点，命令行界面
- **特性**: 
  - 支持交互式和单次请求模式
  - 系统环境检查
  - 友好的用户界面

### 2. app_config.py - 配置管理
- **功能**: 统一的系统配置管理
- **包含**:
  - API Key配置
  - 模型参数设置
  - MCP连接配置
  - 工作流配置

### 3. mcp_client.py - 核心客户端
- **功能**: LangGraph工作流实现和MCP客户端
- **特性**:
  - 多Agent协作逻辑
  - 4阶段工作流程
  - 异步处理支持

### 4. unified_mcp_server.py - Agent工具服务器
- **功能**: 统一的MCP服务器，包含所有Agent工具
- **工具数量**: 17个专业工具
- **分类**: 研究、写作、审核、润色四大类

## 🚀 使用方式

### 快速开始
```bash
# 1. 配置API Key
export DASHSCOPE_API_KEY="your_api_key"

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行系统
python main.py
```

### 命令行选项
```bash
python main.py                           # 交互式模式
python main.py --request "写一篇AI文章"   # 单次请求
python main.py --check                   # 系统检查
python main.py --help                    # 帮助信息
```

## 🔄 工作流程

1. **🔍 研究阶段** → 分析主题，收集信息
2. **✍️ 写作阶段** → 基于研究创作内容  
3. **🔍 审核阶段** → 评估质量，提供反馈
4. **✨ 润色阶段** → 优化内容，最终检查

## 📊 技术架构

- **LangGraph**: 工作流编排和状态管理
- **MCP协议**: Agent间通信和工具调用
- **通义千问**: 大语言模型推理
- **FastMCP**: 高性能MCP服务器框架
